# WDJ Boat Race AI Web v14 過去5年収集版

## 追加機能
- BOAT RACE公式の確定結果を収集
- 開始日・終了日・場・レース数を指定
- SQLiteへ途中保存
- 次回開始候補を保持
- 収集済みCSVをダウンロード
- V13の過去学習機能を継続

## 運用方法
5年分を一度に取得せず、1〜3日・4場程度ずつ実行してください。
全24場は場を分けて繰り返します。

## 現時点の範囲
自動収集は公式の確定結果です。
梅吉AI・ポセイドンの過去予想は、公開保存されている期間が不明なため、
取得可能性を確認した上で後続版へ追加します。

## 注意
Renderの再デプロイでSQLiteが消える構成の場合があります。
長期保存にはPersistent Diskまたは外部DBが必要です。
