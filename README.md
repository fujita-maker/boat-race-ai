# WDJ Boat Race AI Web v5

## v5の主な変更
- 毎レース必ず参考買い目を表示
- 買い目ごとに直前オッズを表示
- 買い目ごとに購入額を表示
- 買い目ごとに的中時払戻を表示
- 買い目ごとに純利益を表示
- 買い判定は総額5,000円
- 少額判定は総額2,000円
- 見送り判定は購入額0円
- 最大払戻、最小払戻、最大純利益を表示
- 実購入チェックがない場合は検証予測として記録
- 締切前予想を固定し、結果後に変更しない
