# WDJ Boat Race AI Web v7

## 実用版の動作
- BOAT RACE公式、梅吉AI、ポセイドンを取得
- 梅吉AIは公開予想ページへ直接アクセス
- 取得失敗時は再試行
- 外部AIの買い目が取れなくても、枠と展示から参考予想順位を生成
- 毎レース必ず6〜8点の参考予想を表示
- WDJ115-v2購入条件を満たした場合だけ5,000円で仮想購入
- 条件未達は購入額0円で見送り
- 買い目、直前オッズ、購入額、的中時払戻、純利益を表示
- 結果登録、場別・季節別・風向別集計

## 重要な制約
外部サイトの停止、アクセス制限、HTML変更があるとデータを取得できない場合があります。
その場合も参考予想は表示しますが、実購入判断は0円見送りにします。
利益や的中は保証しません。
