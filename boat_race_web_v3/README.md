# WDJ Boat Race AI Web v2

## 主な機能
- 公式・梅吉AI・ポセイドンの3サイト取得
- WDJ115-v2による条件判定
- 期待値1.10未満、情報不足、条件不適合は0円見送り
- 実購入・検証予測を分離
- SQLiteへ締切前固定
- 場別・季節別・風向別の成績集計
- 過去予想・収支ダッシュボード
- 結果登録後も事前予想は変更しない

## Web公開
RenderでNew Web Serviceを作成し、このフォルダをGitHubへ置いて接続してください。
`render.yaml` と `Dockerfile` を同梱しています。

## 注意
「画面を閉じても締切3分前に完全自動実行」するには、常駐ワーカーと締切時刻の自動取得が必要です。
このv2では画面を開いた状態の監視UIと、Web公開可能な基盤まで実装しています。


## v3変更
- データ不足でも毎レース必ず参考予想を8点まで表示
- 最終判断を「買い・少額・見送り」の3段階表示
- 自信度を★1〜5で表示
- 予想表示と実購入判断を分離
- 買い条件を満たしたときだけ5,000円の資金配分
- 情報取得が少ない場合は低い星で参考予想として表示
